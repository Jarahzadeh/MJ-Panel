**MJ Panel is a Cloudflare Workers and D1 based network proxy management panel.**

## Features

* Modern RTL-friendly dashboard
* User, quota, and subscription management
* QR and link generation for each user
* Dark mode and responsive mobile layout
* Backup and restore tools
* Proxy rotation and custom routing support
* Fast edge deployment on Cloudflare Workers

## Quick Start

1. Upload the project to your GitHub repository.
2. Connect the repository to Cloudflare Workers.
3. Add the D1 database binding.
4. Deploy the Worker and open the panel.
